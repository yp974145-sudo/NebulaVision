## 每块交付的固定格式

1. 本块需求与验收。
2. 修改的具体文件、调用链与依赖。
3. 技术原理：对象/数据归属、线程、失败分支。
4. 实际执行与结果，明确未测项。
5. 3–5道面试追问，附答案要点并指向代码。
6. 用户练习：一个小修改或一次故障复现，不只复制代码。

## 第一块教学示例：Qt信号槽和异步查询

点击查询触发信号，槽收集参数；工作线程执行查询后发出结果信号，GUI线程槽更新表格。AutoConnection在信号发出时根据接收对象线程与当前执行线程判断直接或排队；排队调用依赖接收线程事件循环。不能简单认为“用了信号槽就自动异步”。数据库连接在使用线程创建和使用，不能将原默认连接交给线程池任意线程。

面试：1. DirectConnection在哪个线程执行？答：发射信号的当前线程。2. QueuedConnection在哪执行？答：接收对象所属线程的事件循环。3. 查询结果乱序怎么处理？答：请求序号或generation，忽略旧结果。4. 窗口关闭时任务没结束怎么办？答：取消/限制任务生命周期，通过带context连接及安全对象引用避免悬空访问，线程必须受控退出。5. 超时是否等于取消？答：不是，调用方不等待不代表底层执行停止，需要明确驱动和取消机制。
