# 窗口缩放和暂停重播修复

2026-11-02，Qt6 Release。

## 原因与修改
主窗口原最低1800×1000，限制正常笔记本窗口缩小；按钮一长排和图片尺寸提示继续撑大布局。
现按Qt逻辑像素和屏幕可用区域确定初始尺寸，最低目标960×640且受屏幕边界限制；按钮分三行，显示控件使用Ignored尺寸策略，左侧范围180至240，深色背景文字改浅色。
原resume仅恢复仍运行的线程；停止或自然结束后没有创建新任务。现保留有效视频来源，继续时若任务已结束就复制来源并重新open，从头重播。
open开始清除旧来源，避免打开无效文件后继续意外播放前一个文件。使用来源副本，避免open清空同一成员导致引用失效。
新增全部暂停和全部继续/重播；暂停保留任务，停止释放任务，重播从头开始。原全部停止语义保留。

## 测试
Qt6主项目及ui_playback_check编译通过。完整MainWidget逻辑尺寸1000×700，布局最低提示790×425。
四路实际帧验证：全部暂停帧数稳定；全部继续四路重新增长；全部停止后继续四路从头播放；1秒视频任务自然结束后继续，重新产生视频帧；放大后再次缩小正常。测试退出码0。
1秒片尾验证只要求重新输出有效帧，不要求至少3次GUI刷新，因为容量1缓存允许短片集中输出时丢旧帧。
截图和日志位于x/验证记录/窗口播放修复。没有重新进行Qt5运行回归。
