# 本机接口契约

开发地址http://127.0.0.1:18880，除health、login和媒体回调外，需Authorization: Bearer令牌。
所有id用十进制字符串，避免跨语言整数精度问题。日期使用UTC yyyy-MM-dd，分页size 1到100。

|接口|方法|用途|
|---|---|---|
|/health|GET|进程健康|
|/api/login|POST|username/password换内存会话令牌|
|/api/logout|POST|令牌失效|
|/api/me|GET|当前用户和admin标志|
|/api/cameras|GET|权限过滤的设备与在线状态|
|/api/camera?id=ID|GET|单设备权限验证|
|/api/cameras/heartbeat|POST|管理员cameraId/ttl续期|
|/api/status|GET|Redis与限流降级状态|
|/api/events?page=1&size=10&date=2026-11-02|GET|事件分页，返回recordingId证据|
|/api/media/play|POST|cameraId申请read范围媒体地址|
|/api/media/publish|POST|管理员申请publish范围媒体地址|
|/internal/media/auth|POST|MediaMTX回调，必须提供有效签名媒体凭据|
|/api/recordings/capture|POST|管理员cameraId/seconds录制一段，202返回id|
|/api/recordings|GET|权限过滤的录像分页|
|/api/recordings/file?id=ID|GET|鉴权下载ready录像，开发上限64MiB|
|/api/detections/start|POST|管理员recordingId/jobKey/threshold/roi发起任务|
|/api/detections/job?id=ID|GET|查询本人任务或管理员任务|

检测任务ROI为归一化[x1,y1,x2,y2]，默认整帧。jobKey为8到64位字母数字下划线短横线。
400参数错，401未登录或过期，403越权，404不存在或不可见，409状态/幂等冲突，410索引有但文件缺失，413下载超限，429限流/队列满，503依赖故障。
错误只给有限信息，不返回密码、令牌和服务器完整磁盘路径。
当前本机开发协议，不等同于互联网生产部署，后续需TLS、容量控制、备份、监控和长期测试。
